# 窥岛 · PEEP ISLAND

> 你不进入这个世界。
> 你只是隔着一块屏幕，低头看着一座小岛上的几个人过日子——
> 直到某一天，她们发现你在看。

一款 AI 驱动的**观察类**生活模拟游戏。React + Express + SQLite，支持 Claude / DeepSeek / Kimi / Gemini 四引擎运行时热切换。

---

## 这是什么

游戏界面被包裹在一个**手机壳**里。这不是装饰，是规则：岛民和你之间存在物理隔离，他们的每一句话都必须是"打字发出来的"——不能有动作描写、不能有旁白、不能出现"（她笑了笑）"这类舞台提示。这条约束由后处理**强制执行**（括号内容与他人台词整行丢弃）。

你能得到的只有文字、时间戳和已读回执。就像真的在跟一个远方的人聊天。

而岛上的人并不为你而活。他们有自己的作息表、心情、烦恼和彼此之间的关系；你不在的时候他们照样过日子，你回来时收到一份"离岛报告"。

---

## 三个核心设计

### 1. 第四面墙：她们也一直在看你

本作的核心设定**不是**"角色某天发现了玩家"，而是——**她们一直都知道**。你以为你在窥视一座岛，其实这座岛也一直在回望你。所谓"破壁"，不是她发现了你，是她第一次决定让你知道她知道。

于是状态机每一级的含义都是**披露程度**，不是察觉程度：

| 状态 | 含义 |
|---|---|
| `unaware` | 她早就知道，只是还没打算让你知道她知道 |
| `hint`（亲密 30） | 她开始**故意**留线索，语气和平常一模一样 |
| `crack`（亲密 50 + 24h 真实时间门控） | 她第一次承认。用最平的语气。 |
| `silent` | 说过了，回到默契，绝不重提 |
| `after` | 心照不宣 |

时间门控挡住了改系统时间加速——**破壁必须真的等**。

**破壁台词由 AI 生成，但走的是约束生成，三层：**

- **素材层**（`gatherObservations()`）——台词必须锚在一条只属于这个玩家的真实数据上：你在凌晨几点还醒着、你隔了多久才回她、你有几条消息一直没点开、你喂过她讨厌的东西、她记得你骂过她的哪句话。**"不重样"来自每个玩家的数据不同，而不是来自模型的随机性。**
- **禁令层**（`crackSystem()`）——负面约束远比正面约束有效。最重的三条：**禁止表达惊讶**（她不惊讶，因为她一直都知道）、**禁止提问**（不给玩家反驳的接口）、**语气必须与她平日完全一致**（不许突然变文艺）。外加禁词表：存在/注视/屏幕/游戏/玩家/创造/命运——说破即失败。
- **判别层**（`validateCrack()`）——生成后自动校验：行数、单行字数、问号、禁词、惊讶词、感叹号颜文字，以及**语气基线**（拿她最近 10 条真实发言的平均行长做基准，偏离过大说明"她突然变了个人"）。不过则重 roll，两次不过降级到人工兜底库。

因此手写库从主路径退为**安全网**——最坏情况等于改动前。

> **设计原理：恐怖不该由角色演出来。**
> 角色一旦表现出害怕，玩家就有了情绪出口，反而松弛；角色若无其事地陈述一件她不该知道的事，那份违和才会完整地压在玩家身上。
>
> 实际生成样例（DeepSeek，判别一次通过）：
> ```
> 你还在看，7月29号凌晨两点那次也是。
> 冰箱里剩的鱼该扔了。
> ```
> 第二行是关键——她**转开了**。你没有反驳的接口，也没有确认的接口。

更进一步，这件事在岛上**扩散**：承认过的角色会私下跟关系最近的挚友（≥40）说一句"他快发现了"；那位朋友被标记 `fw_rumor`，从此多留意你的反应，但永远不说破。**岛民之间在讨论你——他们是共谋，不是受害者。**

### 2. 对抗"AI 味"的工程手段

这是开发中最耗时的部分。大模型天生谄媚、有求必应、车轱辘话——这些全是本作的敌人。

| 机制 | 做法 |
|---|---|
| **沉默权** | 角色可以选择"已读不回"。你会看到已读回执，然后什么也没有。 |
| **后果系统** | 辱骂角色 → 好感度下降 + 生成一条"伤疤记忆" + 六小时低落心情。她记得。 |
| **不重复规则** | 一个问题被你无视或攻击之后，她永远不会问第二次。 |
| **节奏系统** | 消息延迟 8–88 秒送达；"正在输入"只在到达前 7 秒出现，而不是全程亮着；睡眠时段（普通 23–7 / 夜猫 5–12）整夜不回，隔夜未读转为次日清晨的回复。 |
| **危机识别** | 识别到自伤类表达时，角色立刻放下全部人设——先当人，再当聪明人，不分析、不表演。 |
| **托底透明** | 超出每日配额时走脚本台词，UI 明确打上「脚本」标，不假装是 AI。 |

**统计层：把"AI 味"当成可测量的量，而不是形容词**

AI 文本检测研究里，区分人类文本和 LLM 文本最稳的两个统计量是 perplexity 和 **burstiness**——后者指长度与结构的方差。人类聊天长短剧烈交替（一句「嗯」后面跟四十个字），LLM 输出高度均匀地挤在均值附近。这就是"AI 味"的统计本体。

关键判断：**不能求模型"多变化一点"，它必然回归均值。** 所以由系统先采样一个目标形状（极短 / 短 / 连发 2-3 条 / 一条长的，概率由亲密度调制），再把形状当指令下发。方差是外部施加的，不是指望它涌现的。

同样的思路贯穿三个机制——**规矩模型不听，门禁它过不去**：

| 机制 | 做法 |
|---|---|
| **形状采样** | 回复长度/条数由系统抽样决定，实测 burstiness 变异系数 0.60–0.82（文献：人类 >0.6，LLM <0.4），长度跨度 1–71 字 |
| **口头禅去重** | 统计该角色最近 12 条回复的开头，把重复的贴回 prompt 让它看见自己——通用机制，不写死任何词 |
| **回复判别器** | 生成后校验明喻／编造做法／破设定，命中则带着违规原因重生成一次。实测触发 11%，打比方残留从满屏降到 2% |

这套"生成 → 判别 → 重 roll → 降级"最早用在第四面墙台词上（判别器 8/8 分类正确），验证有效后推广到了日常对话。

### 3. 观察经济学：把成本约束变成设计语言

岛上 99% 的生活——移动、作息、心情衰减、关系演变、事件触发——是**纯确定性模拟，零 API 成本**；只有当你真正与某人发生交互的那一瞬间，才调用大模型。

没有任何定时器：生成只发生在「你打开」和「你说话」两个时刻，离岛超过 4 小时一次性结算。

这让一座持续运转的活岛在成本上得以成立，也让后续接入实时 2D 岛屿画面时，底层数据结构无需重写。

## 功能一览

**角色与生活**
- 三层人格（表层 / 内层 / 怪癖）+ 夜猫子属性影响深夜活跃度
- 记忆系统：`strength × valence × 14 天衰减`检索 top4；直接对话 strength=1，旁观动态 strength=0.3
- 事件簿：每 24 条对话自动压缩成一篇**第一人称日记**进入长期记忆
- 投喂循环：8 种食物 × 每角色隐藏好恶，每日一次，幸福度 0–100
- 烦恼系统：主动消息 1/3 概率携带烦恼，**你回一句就等于处理了**（幸福 +8 / 亲密 +3）
- 亲密度六阶段命名

**岛与社会**
- 岛屿为主界面：小人按日程表走位，头顶气泡（烦恼❗ > 未读✉️ > 睡着💤 > 没喂🍽）
- 角色卡抽屉：幸福/亲密双条、烦恼框、关系 chips、「TA 眼中的你」画像
- NPC 关系网络（0–100），关系融进每个角色的花名册 prompt——他知道自己和别人什么交情
- **相遇小剧场**：两个醒着的人在同一地点相遇 → 一次 API 生成 3–5 拍的戏（`旁白｜…` / `角色名｜台词`）→ 岛面变暗、两位主角走到台前放大、底部字幕条逐拍播出。你只是观众。
- 岛志：离岛期间生成的第三人称小事
- 窥梦：点一下睡着的角色，偷看一段梦

**捏脸与分享**
- 外观**参数化合成**：发型 6 × 眼 5 × 嘴 5 × 衣 4 + 肤/发/衣自由取色 + 身高 + 腮红
- 不依赖任何预绘立绘，因此玩家新捏的角色和内置角色一样完整
- `PEEP1.` 文本分享码：外观与性格一起传递，朋友粘贴即得同一个角色

**画面**
- **地块渲染**：11×14 网格，地形是一张 14 行的字符表——改岛就是改表，不用碰代码。建筑按占地格数摆放（民居/商店 2×2、灯塔 1×3、码头 2×1）
- **墨水屏模式**（⚙️ 旁一键三档：关 / 四阶灰 / 纯黑白 1-bit）：去色 → 提对比 → Bayer 有序抖动 → 量化到有限灰阶 → 映射到纸墨色。同时关掉全部补间动画——电子墨水刷新要几十到几百毫秒，物理上做不出平滑过渡
- **真像素化**：`image-rendering: pixelated` 只对位图生效，对矢量无效。所以角色是先序列化成 SVG、画进 22×28 的 canvas（关闭插值 = 最近邻点采样）、再放大回去——低分辨率是真的被采样掉的

**开发者工具**
- 五引擎运行时热切换（Claude / DeepSeek / Kimi / MiniMax / Gemini），**key 可直接在界面里填**，存本机、只回显后四位、不用重启
- `//` 对比模式：同一句话同时打给所有已配置引擎，横向比较"人味"
- **心跳验证**（`server/心跳验证.mjs`）：七条各自对准一种 AI 味失败模式的探针，打给所有引擎后**抹掉引擎名、逐条打乱顺序**，生成盲测卷 + 揭晓表
- **分层压测**（`server/百轮压测.mjs`）：临时造 5 个测试角色（L1 完全陌生 → L5 灵肉交合），输入取自 Tatoeba 公开语料而非人工编写，统计 burstiness／剥空率／模板化重复／破设定命中，跑完自动清理
- 内心面板（透明化 debug）、消息导出（带完整机制快照）、每日自动备份

## 技术架构

```
server/
  db.js          # SQLite schema + 角色种子
  brain.js       # prompt 组装 / 记忆检索 / 配额 / 第四面墙状态机 /
                 # 形状采样 + 口头禅去重 + 回复判别器 / 五引擎适配
  fallback.js    # 脚本托底台词
  index.js       # 惰性生成、聊天、动态、剧场、场景、静态托管
  心跳验证.mjs   # 盲测工具
  百轮压测.mjs   # 分层健康度压测
client/
  App.jsx        # 手机壳 UI（岛 / 聊天 / 动态 / 设置 / 墨水屏管线）
  Avatar.jsx     # 参数化角色渲染器 + PixelAvatar（栅格化像素版）
  Scene.jsx      # 地块渲染：网格、地形表、地点↔格子映射、建筑占地
  public/        # 美术投放位：tiles / props / buildings / fonts
```

**渲染层是可替换的**——美术接入只需往目录里丢图，数据结构和代码完全不动：

| 放什么 | 目录 | 说明 |
|---|---|---|
| 地形块 32×32 | `public/tiles/` | `background-color` 垫底 + `background-image` 覆盖，图片 404 时浏览器保留底色，所以"有图用图、没图用色"不需要任何判断逻辑 |
| 装饰物 | `public/props/` | 透明背景 |
| 建筑白模 | `public/buildings/` | 灰度，运行时染色；`<img onError>` 回落到矢量形状 |
| 中文像素字体 | `public/fonts/zpix.woff2` | 中文像素字体没法靠系统字体栈拿到，必须嵌入；文件不存在时静默回落到等宽字体 |

草地放 `grass_1/2/3` 三个变体时，系统按格子位置轮换，自动打散重复感。

> 给美术的方向：tile 画成**线稿 + 网点**，不要写实纹理。写实纹理在墨水屏模式下会糊成一片，线稿在彩色模式下也照样好看——一套资源两种模式通吃。

## 本地运行

需要 Node 20.6+。**不填任何 key 也能完整跑通**（自动进入脚本托底模式）。

```bash
# 1. 服务端
cd server && npm install
cp .env.example .env          # 填入你有的 key，四家任一即可
npm start                     # http://localhost:3711

# 2. 前端（开发模式，热更新）
cd client && npm install && npm run dev   # http://localhost:5173
```

一键版：双击项目根目录的 **`窥岛.command`**（自动起 server 并打开浏览器；改了前端要先 `cd client && npm run build`）。

### 配 API key：两种方式，任选

**① 界面里填（推荐，不用重启）**
右上角 ⚙️ → 引擎列表 → 点「填入」→ 粘贴 → 存。
key 存在本机 `server/island.db`，**不上传任何服务器**；界面与接口一律只回显后四位，服务端日志不记录明文。

**② 写进 `server/.env`**（全部见 `server/.env.example`）

| 变量 | 说明 |
|---|---|
| `AI_PROVIDER` | 默认引擎 `claude｜deepseek｜kimi｜minimax｜gemini`，不填则自动选第一个有 key 的 |
| `ANTHROPIC_API_KEY` / `DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` / `MINIMAX_API_KEY` / `GEMINI_API_KEY` | 各家 key，不必都填 |
| `DAILY_QUOTA` | 每角色每日真实 AI 上限，默认 5（超出走托底） |
| `CATCHUP_HOURS` | 离岛多久触发离岛报告，默认 4 |
| `*_MODEL` / `*_BASE` | 覆盖各家默认模型与接口地址 |

界面里填的优先于 `.env`。两个都不填也能完整跑通——自动进入脚本托底模式。

## 部署

仓库根目录已含 `render.yaml`（Render Blueprint），可直接从 GitHub 一键部署。
其他平台构建/启动命令：

```bash
# build
cd client && npm ci && npm run build && cd ../server && npm ci
# start
cd server && node index.js      # 监听 $PORT
```

> ⚠️ 公开部署注意：SQLite 是单文件本地库，所有访客共用同一座岛；且 API key 在服务端，**务必把 `DAILY_QUOTA` 调回小值**避免额度被耗尽。

## 设计约束（明确不做）

吃醋状态机 / 语音 / 多模态 / UGC / 岛屿建设 / 结婚生子 / 云同步。
角色数上限 6–8 人——不是技术限制，是 API 成本写进设计的结果。
